# java-lotto-precourse

## 아이디어
- 1~45까지의 숫자를 랜덤으로 뽑는다. 
- 중복없이 6장을 뽑아야 하기 때문에 중복을 제거하는 로직이 필요하다.
- 입력 번호와 당첨 번호를 비교할 때 겹치는 숫자만 남기는 로직이 필요하다.
- 교집합으로 남은 번호들을 카운트해 당첨 통계에 횔용한다. (set의 retainAll()?)
- 통계를 바탕으로 수익을 더해 구입금액으로 나눠 수익률을 계산한다.

## 구현 목록 
1. 로또 금액을 입력 받는 함수를 구현한다.(1000원 단위)
2. 당첨 번호와 보너스 번호를 입력 받는 함수를 구현한다.(6+1개)
3. 랜덤숫자를 받는 함수를 구현한다. (중복없는 6개의 숫자를 뽑아 만든 리스트를 Lotto 객체에 담는다.)
4. Lotto 클래스에 입력번호와 당첨번호를 비교하는 매서드를 구현해 일치하는 숫자 개수를 반환한다.
5. 당첨 내역을 출력하는 함수를 구현한다. 
6. 당첨 내역의 합계를 구해 수익률을 출력하는 함수를 구현한다.


## 에러처리
#### 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
#### Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.
- 번호가 중복되는 경우(입력 번호 +당첨 번호, 당첨 번호)
- 입력한 번호가 숫자가 아닐 경우 
- 입력 번호가 45를 넘어가는 경우
- 1000원 단위로 나누어 떨어지지 않는 경우
